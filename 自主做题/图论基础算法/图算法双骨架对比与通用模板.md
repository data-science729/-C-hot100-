# 🗺️ 图算法核心双骨架：抽象通用图 vs 二维网格图

> **导读**：  
> 无论是面试、竞赛还是深度学习底层，图论题目千变万化，但**底层模板永远只有两套形态**：  
> 1. **抽象通用图（边表/邻接表）**：节点是离散编号（0, 1, 2...），边由显式列表给出（如课程表、朋友圈、依赖图）。  
> 2. **具象网格图（二维棋盘/地图）**：节点是坐标 `(r, c)`，边是上下左右 4 个方向（如岛屿数量、走迷宫）。

## 一、 骨架一：抽象通用图模板（邻接表 + Visited）

### 1.1 核心思想与适用题型
* **适用题目**：LeetCode 207/210（课程表/拓扑排序）、LeetCode 547（省份数量/朋友圈）、网络连通性。
* **数据结构**：
  * 邻接表：`vector<vector<int>> adj`（`adj[u]` 存节点 `u` 的所有邻居）；
  * 打卡表：`vector<bool> visited`（防止在环路中鬼打墙死循环）。

### 1.2 C++ ACM 模式完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// ============================================================================
// 1. 全局图状态
// ============================================================================
int N;                          // 节点总数 (编号 0 ~ N-1)
vector<vector<int>> adj;        // 邻接表
vector<bool> visited;           // 访问打卡表

// ============================================================================
// 2. 遍历引擎 A：深度优先搜索 (DFS) —— 递归栈驱动
// 哲学：一条路探到底，不撞南墙不回头
// ============================================================================
void dfs(int u)
{
    visited[u] = true; // 1. 到站打卡

    // 2. 顺着邻接表，探索所有相连的邻居 v
    for (int v : adj[u])
    {
        if (!visited[v]) // 没去过的邻居才去
        {
            dfs(v);
        }
    }
}

// ============================================================================
// 2. 遍历引擎 B：广度优先搜索 (BFS) —— 先进先出队列驱动
// 哲学：波纹式层层向外扩散，天然保证无权图最短路径
// ============================================================================
void bfs(int startNode)
{
    queue<int> q;

    visited[startNode] = true; // 起点打卡
    q.push(startNode);

    while (!q.empty())
    {
        int u = q.front();
        q.pop();

        for (int v : adj[u])
        {
            if (!visited[v])
            {
                visited[v] = true; // ★关键：入队的同时必须打卡，防止重复入队！
                q.push(v);
            }
        }
    }
}

// ============================================================================
// 3. 宏观指挥官：统计图中有多少个互不相连的独立连通块
// ============================================================================
int countConnectedComponents()
{
    visited.assign(N, false); // 打卡表初始化
    int count = 0;

    // 巡逻所有节点：只要遇到没访问过的，就说明找到了一个新分支！
    for (int i = 0; i < N; ++i)
    {
        if (!visited[i])
        {
            count++; // 连通块总数 + 1
            dfs(i);  // 派兵清场：把该分支的所有节点一次性全标记掉！
        }
    }
    return count;
}

// ============================================================================
// 4. ACM 驱动入口
// ============================================================================
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int M; // 边的数量
    // 读入点数 N 和 边数 M
    while (cin >> N >> M)
    {
        adj.assign(N, vector<int>());

        for (int i = 0; i < M; ++i)
        {
            int u, v;
            cin >> u >> v;
            // 添加无向边 (若为有向边则只需第一行)
            adj[u].push_back(v);
            adj[v].push_back(u);
        }

        cout << "独立连通块数量: " << countConnectedComponents() << '\n';
    }
    return 0;
}
```

## 二、 骨架二：二维网格图模板（坐标 + 方向数组 + 原地沉岛）

### 2.1 核心思想与适用题型
* **适用题目**：LeetCode 200（岛屿数量）、LeetCode 695（岛屿最大面积）、LeetCode 994（腐烂的橘子）、迷宫寻路。
* **数据结构**：
  * 地图底座：`vector<vector<char>> grid` 本身就是图，不需要显式建 `adj`；
  * 方向向量：`dx = {-1, 1, 0, 0}`, `dy = {0, 0, -1, 1}` 动态计算上下左右邻居；
  * 打卡机制：**原地沉岛（把 `'1'` 直接改写为 `'0'`）**，不仅省去 `visited` 数组开销，更直观简洁。

### 2.2 C++ ACM 模式完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 方向辅助数组：上、下、左、右
const int dx[4] = {-1, 1, 0, 0};
const int dy[4] = {0, 0, -1, 1};

// ============================================================================
// 1. 微观探路：网格 DFS 沉岛
// 任务：将与 (r, c) 相连的整块陆地全部变为水 ('0')
// ============================================================================
void dfsGrid(vector<vector<char>>& grid, int r, int c, int m, int n)
{
    // 递归出口：越界 或者 当前是水 ('0')
    if (r < 0 || r >= m || c < 0 || c >= n || grid[r][c] == '0')
    {
        return;
    }

    // 核心动作：原地打卡（沉岛），把陆地变成水，防止后续重复访问死循环
    grid[r][c] = '0';

    // 顺着上下左右 4 个方向深探
    for (int i = 0; i < 4; ++i)
    {
        dfsGrid(grid, r + dx[i], c + dy[i], m, n);
    }
}

// ============================================================================
// 2. 宏观巡逻：统计岛屿数量（连通块总数）
// ============================================================================
int countIslands(vector<vector<char>>& grid)
{
    if (grid.empty() || grid[0].empty()) return 0;
    int m = grid.size();
    int n = grid[0].size();
    int islands = 0;

    // 直升机全图扫描
    for (int i = 0; i < m; ++i)
    {
        for (int j = 0; j < n; ++j)
        {
            // 只要发现没沉没的陆地，说明发现了新岛屿！
            if (grid[i][j] == '1')
            {
                islands++;                         // 岛屿总数 + 1
                dfsGrid(grid, i, j, m, n);         // 派特种兵沉掉整座大岛
            }
        }
    }
    return islands;
}

// ============================================================================
// 3. ACM 驱动入口
// ============================================================================
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int m, n;
    while (cin >> m >> n)
    {
        vector<vector<char>> grid(m, vector<char>(n));
        for (int i = 0; i < m; ++i)
        {
            for (int j = 0; j < n; ++j)
            {
                cin >> grid[i][j]; // 自动跳过空白字符与换行
            }
        }

        cout << countIslands(grid) << '\n';
    }
    return 0;
}
```

## 三、 降维打击：两大骨架 1 对 1 映射表

当把两份代码并排摆在一起时，你会发现它们**本质完全同构**：

| 算法概念 | 骨架一：抽象通用图 | 骨架二：二维网格图 | 为什么本质完全相同？ |
| :--- | :--- | :--- | :--- |
| **节点编号** | `int u`（标量） | `(r, c)`（二维坐标） | 都是为了唯一标识图上的一个具体位置。 |
| **邻居获取** | `for (int v : adj[u])` | `for i in 0..3: (r+dx[i], c+dy[i])` | 抽象图靠列表查邻居；网格图靠几何加减找邻居。 |
| **越界防御** | 节点编号天然在 `[0, N-1]` 之间 | 必须严格判断 `r >= 0 && r < m ...` | 网格边界可能会走出地图外。 |
| **打卡标记** | `visited[u] = true;` | `grid[r][c] = '0';` | 都是为了告诉后续遍历：“这里来过了，别再走了！” |
| **宏观调度** | 单层循环 `for (int i = 0; i < N; ++i)` | 双重循环 `for i: 0..m` + `for j: 0..n` | 扫遍全图，保证散落的独立连通块一个不漏。 |
| **统计指标** | 连通块数量 `componentCount` | 岛屿数量 `islands` | **完全是同一个物理概念的不同命名！** |

## 四、 避坑指南与核心口诀

### 1. DFS 递归出口三要素（刻在 DNA 里）：
* **越界检查**：是否跑出坐标合法范围？
* **类型检查**：当前是不是目标类型（是不是碰到了水 `'0'`）？
* **重复检查**：当前节点是否已经访问过（是否已打卡）？

### 2. BFS 的“黄金打卡时机”（90% 初学者踩过的坑）：
* **必须在【入队的同时立刻打卡】**（`visited[v] = true; q.push(v);`）；
* **绝不能在【出队的时候才打卡】**！如果在出队时打卡，同一个邻居节点会被多个上游节点反复加进队列，导致队列指数级膨胀，瞬间爆内存（MLE/TLE）！
