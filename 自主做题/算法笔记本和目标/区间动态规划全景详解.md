## 一、 宏观认知：什么是区间 DP？

### 1. 核心定义
* **状态定义**：`dp[i][j]` 通常表示序列中闭区间 $[i, j]$（从下标 $i$ 到 $j$ 的连续子串或子数组）的最优值、可行性或方案数。
* **转移本质**：**由短区间推导长区间**。

### 2. 它与其它 DP 的差异对比

| DP 类型 | 阶段推进方式 | 状态转移方向 | 经典问题 |
| :--- | :--- | :--- | :--- |
| **线性 DP** | 时间/下标单向推进 | 从前缀 $i-1$ 推导到 $i$ | 爬楼梯、打家劫舍、最长递增子序列 (LIS) |
| **背包 DP** | 物品数量与容量递增 | 容量维度的选择与累加 | 0-1 背包、完全背包 |
| **区间 DP** | **区间长度从小到大** | **从小区间向外扩展或合并为大区间** | **回文串、矩阵链乘、石子合并、表达式求值** |

## 二、 历史背景与工程应用

1. **《算法导论》起源：矩阵链乘 (Matrix Chain Multiplication)**
   * 计算矩阵乘法序列 $A_1 \times A_2 \times \dots \times A_n$。不同结合顺序（加括号方式）会导致计算量差上万倍。
   * 如何加括号最省计算量？这正是枚举切分点 $k$ 的经典区间 DP。
2. **NLP 与编译原理：句法分析 CYK 算法 (Cocke-Younger-Kasami)**
   * 在计算语言学中，将句子的单词序列还原为句法树（Parse Tree）。CYK 算法正是用标准的区间 DP，从小语法短语逐步归并出整棵句法树。
3. **最优二叉搜索树 (Optimal BST)**
   * 按照节点的查询频率构造查找代价最低的二叉搜索树。

## 三、 核心架构：区间 DP 的两大流派

```
                ┌──────────────────────────────────┐
                │          区间动态规划             │
                └────────────────┬─────────────────┘
                                 │
         ┌───────────────────────┴───────────────────────┐
         ▼                                               ▼
【流派一：两端收缩型（剥洋葱）】               【流派二：中间切分点型（合并/裂解）】
- 依赖: [i+1, j-1] / [i+1, j] / [i, j-1]       - 依赖: [i, k] 与 [k+1, j]
- 时间复杂度: O(n²)                             - 时间复杂度: O(n³)
- 典型代表: 回文子串/回文子序列                  - 典型代表: 石子合并、戳气球、多边形三角剖分
```

### 流派 1：两端收缩型（剥洋葱模型，时间 $O(n^2)$）
* **核心机制**：大区间 $[i, j]$ 的性质，仅取决于**两个端点元素 $s[i], s[j]$ 以及剥除端点后的小区间**。
* **通用转移形式**：
  $$dp[i][j] = f(dp[i+1][j-1], \ dp[i+1][j], \ dp[i][j-1])$$
* **经典场景**：
  * **LeetCode 5. 最长回文子串**：判定性问题，首尾相同且内部回文：
    $$dp[i][j] = (s[i] == s[j]) \land dp[i+1][j-1]$$
  * **LeetCode 516. 最长回文子序列**：求最长长度，首尾匹配 $+2$，不匹配则两头各缩一位取大值：
    $$dp[i][j] = \begin{cases} dp[i+1][j-1] + 2 & s[i] == s[j] \\ \max(dp[i+1][j], dp[i][j-1]) & s[i] \ne s[j] \end{cases}$$

### 流派 2：中间切分点型（合并/裂解模型，时间 $O(n^3)$）
* **核心机制**：大区间 $[i, j]$ 不能简单看两端，必须由中间某一个**切分点 $k$**（$i \le k < j$）将区间切为 $[i, k]$ 和 $[k+1, j]$ 两半合并而来。
* **通用转移形式**：
  $$dp[i][j] = \min_{i \le k < j} \Big( dp[i][k] + dp[k+1][j] \Big) + \text{Cost}(i, j)$$
* **经典场景**：
  * **石子合并**：合并相邻两堆石子的最小代价。
  * **LeetCode 312. 戳气球**：逆向思维，枚举最后被戳破的气球 $k$。
  * **LeetCode 1039. 多边形三角剖分的最低得分**：枚举底边构成的三角形顶点 $k$。

## 四、 核心命门：遍历顺序与万能黄金模板

### 1. 为什么常规遍历会出错？
如果写成：
```cpp
// ❌ 错误示范：
for (int i = 0; i < n; ++i) {
    for (int j = i; j < n; ++j) {
        dp[i][j] = dp[i + 1][j - 1]; // 严重错误！计算 i 时，i+1 行还没计算！
    }
}
```

### 2. 标准长度递增模板（背诵级）
必须保证**“短区间一定先于长区间计算完毕”**，通用循环模式如下：

```cpp
// 🌟 区间 DP 万能黄金模板
for (int len = 1; len <= n; ++len) {          // 1. 枚举区间长度 len (从 1 到 n)
    for (int i = 0; i + len - 1 < n; ++i) {   // 2. 枚举左端点 i
        int j = i + len - 1;                  //    计算右端点 j
        
        // 基础边界（长度为 1 或 2）
        if (len == 1) {
            dp[i][j] = 初始值;
            continue;
        }

        // 分支 A：两端收缩型 (O(n²))
        // dp[i][j] = ... 由 dp[i+1][j-1] 等转移而来

        // 分支 B：切分点枚举型 (O(n³))
        // for (int k = i; k < j; ++k) {
        //     dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j));
        // }
    }
}
```

## 五、 经典实战：LeetCode 5 最长回文子串（区间 DP 实现）

```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;

string longestPalindromeIntervalDP(const string& s) {
    int n = s.size();
    if (n <= 1) return s;

    // dp[i][j] 表示子串 s[i...j] 是否为回文
    vector<vector<bool>> dp(n, vector<bool>(n, false));

    int max_len = 1;
    int start = 0;

    // 按区间长度 len 从 1 到 n 递增枚举
    for (int len = 1; len <= n; ++len) {
        for (int i = 0; i + len - 1 < n; ++i) {
            int j = i + len - 1;

            if (s[i] == s[j]) {
                if (len <= 2) {
                    dp[i][j] = true; // "a" 或 "aa"
                } else {
                    dp[i][j] = dp[i + 1][j - 1]; // 依赖更短的子区间
                }
            } else {
                dp[i][j] = false;
            }

            if (dp[i][j] && len > max_len) {
                max_len = len;
                start = i;
            }
        }
    }

    return s.substr(start, max_len);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    while (cin >> s) {
        cout << longestPalindromeIntervalDP(s) << "\n";
    }
    return 0;
}
```

## 六、 区间 DP 的三大“实战法宝”

1. **前缀和加速区间合并代价**：
   * 在石子合并中，求 $\sum_{t=i}^j stones[t]$ 若每次内层累加会导致 $O(n^4)$；
   * 采用前缀和数组 `prefix[j+1] - prefix[i]` 将代价查询降至 $O(1)$。
2. **破环成链（环形问题化为线性）**：
   * 当首尾相连呈圆环时，将数组复制一份拼在尾部形成 $2n$ 长度链，枚举 $[i, i+n-1]$ 的最值。
3. **逆向思维（吹气球模型）**：
   * 如戳气球问题，正向考虑“先戳破谁”会导致剩余两边重新相连带来强耦合；
   * 逆向考虑“**最后一个被戳破的气球是 $k$**”，子区间 $[i, k]$ 与 $[k, j]$ 就完全独立，可以优雅分治合并。
