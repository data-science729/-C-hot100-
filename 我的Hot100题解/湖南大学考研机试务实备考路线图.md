## 二、 考场 4 题题型梯度与抢分策略

湖大机试通常为 **4 道题**（每题 25 分，共 100 分），分值与题型结构具有极其鲜明的梯度：

```text
[第1题 签到题] (25分) ──► 程序设计基础：字符串处理 / 进制转换 / 日期模拟 / 大数高精度
[第2题 基础算法] (25分) ──► 排序查找 / 贪心 / 双指针 / 二分查找 / 简单递归
────────────────── 目标及格线：稳拿 50 分 ──────────────────
[第3题 分水岭题] (25分) ──► 搜索（DFS/BFS 迷宫连通块） / 线性DP与背包问题
[第4题 压轴拉分题] (25分) ──► 图论核心（Dijkstra最短路 / 并查集 / Kruskal / 拓扑排序）
────────────────── 目标高分线：冲击 75~100 分 ────────────────
```

* **保底原则**：第 1、2 题必须在 **45 分钟内做到 100% 满分 AC**，确保 50 分稳落袋中。
* **分水岭攻坚**：第 3 题是拉开普本与高分考生的核心战场，DFS/BFS 模板必须做到肌肉记忆。
* **压轴抢分**：第 4 题哪怕无法拿到最优解，靠**基础暴力或特判**也能捞到 8~15 分的部分测试点。

## 三、 四阶段务实学习路线（时间表与任务清单）

### 模板 2：二分查找（寻找左边界）
```cpp
int bsearch(int l, int r, int target, const vector<int>& a) {
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] >= target) r = mid;
        else l = mid + 1;
    }
    return l;
}
```

### 模板 3：网格搜索（DFS 连通块模板）
```cpp
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};
void dfs(int x, int y, int n, int m, vector<vector<int>>& grid) {
    grid[x][y] = 0; // 标记已访问
    for (int i = 0; i < 4; i++) {
        int nx = x + dx[i], ny = y + dy[i];
        if (nx >= 0 && nx < n && ny >= 0 && ny < m && grid[nx][ny] == 1) {
            dfs(nx, ny, n, m, grid);
        }
    }
}
```

### 模板 4：并查集（Union-Find）
```cpp
int parent[10005];
int findRoot(int x) {
    return parent[x] == x ? x : parent[x] = findRoot(parent[x]); // 路径压缩
}
void unionSet(int x, int y) {
    int rx = findRoot(x), ry = findRoot(y);
    if (rx != ry) parent[rx] = ry;
}
```

### 模板 5：Dijkstra 最短路（优先队列堆优化版）
```cpp
struct Edge { int to, w; };
vector<Edge> G[1005];
int dist[1005];

void dijkstra(int startNode, int n) {
    fill(dist, dist + n + 1, 1e9);
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;
    dist[startNode] = 0;
    pq.push({0, startNode});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto& e : G[u]) {
            if (dist[u] + e.w < dist[e.to]) {
                dist[e.to] = dist[u] + e.w;
                pq.push({dist[e.to], e.to});
            }
        }
    }
}
```

## 五、 考场高分避雷守则

1. **最后一次提交原则**：
   大纲写明：*“以最后一次提交的程序进行评分”*。如果某一题你经过努力拿到了 20 分的测试点，剩下的 5 分如果你改不出来，**千万不要在最后 5 分钟提交一个会语法报错或崩溃的版本**！
2. **大数组全局开**：
   图的邻接表、大 DP 数组、全局标记数组一律开在 `main()` 函数外部，杜绝 Windows 默认栈溢出（0xC0000005 闪退）。
3. **特判抢分**：
   遇上不会的压轴题，输出题目描述中提到的边界值（如 `-1`、`0`、第一组输入的小计算），能白捡 10%~20% 的分数。
